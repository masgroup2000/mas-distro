MAS notices

What the MIT license covers

The MIT license in LICENSE covers the original MAS software and documentation:

  • the installer and the helper tools that ship with it
  • the live-build configuration, hooks and the documentation

It does not cover the software that MAS is built from, which is described below.

Name and logo

"MAS", "MASDISTRO" and the MAS logo and artwork are not licensed under the MIT license. You may redistribute MAS under the MIT license, but if you modify it and distribute a different version, you must use a different name and logo.

Third-party software

MAS is based on Debian 13 (trixie) and includes software from many other projects, including the Linux kernel, GNU tools, KDE Plasma, Qt and PySide6. Each package keeps its own license, which you can read in /usr/share/doc/<package>/copyright on an installed system.

MAS includes firmware and drivers that are not free software (for example from firmware-misc-nonfree and the Wi-Fi and graphics firmware packages). They are redistributed under their own licenses, which are included in the same /usr/share/doc locations. The proprietary NVIDIA driver, if you choose it, is downloaded from Debian during install and is under NVIDIA's license.

MAS is not affiliated with or endorsed by the Debian Project.

Source code for GPL and similar licenses

Many packages in MAS are licensed under the GNU GPL, LGPL and similar licenses that require source to be available. MAS ships Debian's packages without modification, so the source is Debian's source.

MAS is an independent project. It is not part of Debian and has no repository in Debian.
