MAS Documentation

MAS is a lightweight Linux distro based on Debian 13 (trixie), with a KDE Plasma desktop, encrypted disks and an optional second, independent system on the same disk. It ships as a live ISO.

Quick facts

  • Based on: Debian 13, no custom kernel or patched packages
  • Independent: MAS is not part of Debian and has no repository in Debian
  • Disk: at least 40 GB (80 GB for two profiles). The disk you choose is erased.
  • RAM: 4 GB or more
  • Internet: required during install, because the kernel and desktop are downloaded then
  • Boot modes: UEFI (Secure Boot supported) and legacy BIOS
